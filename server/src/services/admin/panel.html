Moloch's Gauntlet

The monthly event: open for the first days of each month by itself. Open it early (for the usual number of days from now), close it, or leave it to the calendar.

Hell Freezes Over

The one-time story event. While it is on, it starts for each player once every monster on Strongbox pages 1-5 is unlocked. Turning it off stops new players starting; players who started keep going. A player's card can start it, move it on a day, or clear it.

Frozen Monster Invasion

The monthly invasion, for players who have won Hell Freezes Over's last wave. Its days come from the config's calendar, unless it is opened or closed here. A player's card shows their waves and totems, and can start their waves this month again.

Trick or Treat

The Halloween event: one door for each wild tribe, knocked on once (25 Shiny, or 1,000 level 6 Zagnoids round the yard; all killed pays the 25 after all). Its days come from the config's calendar (30 October to 2 November, Chicago time), unless it is opened or closed here. Once it's over, everyone who knocked gets 6 Mini-Pumpkins the next time they're home.

Wart Bloom

Every weekend, Friday 6 pm to Sunday midnight (US Central), warts grow faster in main yards. Skip this weekend's (the rest of it, if it is on), start one now for some hours, or change how much faster. Players' games see it within a minute; the start and end are announced in Global chat as usual.

Player reports

Chat lines and letters players reported, with the lines or letters around them as the server has them. One row for each reported player and kind, with the latest report; the last 5 under it. A letter's sender is blocked for the player who reported it. Mute or ban from the player's card, then dismiss; a new report opens it again.

Cheat detection

Found automatically: each is something the game itself can never send, checked with room to spare, so every row is a changed game or forged requests, never bad luck. The proof is kept with it. Nobody is banned automatically: look, then ban from the player's card, or dismiss.

Attack-violation reports

Attacks the server refused, per player. Ban, or dismiss to set the count back to 0.

Bugs reported by the game

Errors players' games hit, sent automatically. The same problem is grouped into one row. Mark a bug fixed once a fix is published; if it is reported again it comes back here.

Player feedback

What players sent from the game's right-click menu: bug reports and suggestions, in their own words, with what they highlighted and, when they chose to, a screenshot (the highlight is drawn on it) and a picture of their own. ADMIN marks one an admin sent. Set a status and write an answer: the player sees both under My reports in the game (a new answer, or planned, done or not planned, shows as new to them). The note is for admins only. On the server's computer, bun run feedback in server writes the open ones out with their pictures (server\logs\feedback).

Chat

Outpost kits: earlier versions

Each Designer save or reset of a kit keeps a copy of the kit file (inferno-kits.json) as it was before, the last 5. Restore puts all six kits back as they were in that copy and draws their pictures again; the file as it is now is copied first, so a restore can be undone the same way. Players see it the next time they open the kits. A kit's Reset in the Designer still goes back to the kit as it was before anyone changed it.
