Maintenance mode

While on, only admins can log in; everyone else is shown the message. Players already in the game are not thrown out.

Moloch's Gauntlet

The monthly event: open for the first days of each month by itself. Open it early (for the usual number of days from now), close it, or leave it to the calendar.

Hell Freezes Over

The one-time story event. While it is on, it starts for each player once every monster on Strongbox pages 1-5 is unlocked. Turning it off stops new players starting; players who started keep going. A player's card can start it, move it on a day, or clear it.

Announcement

A popup every player sees once, on their next yard load or within a few seconds if they are playing.
